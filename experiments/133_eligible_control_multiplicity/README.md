# Experiment 133 — Multiplicity of pre-intervention exact on-cycle controls

## Question

Experiments 108–132 use the **first** control candidate, among up to 100 random compact raw bit assignments per G0 parent, satisfying exact autonomous period, cycle union-support *positions*, phase-0 occupied positions and scheduler phase. Is there meaningful nonuniqueness in this control selection rule?

## Immutable assay

Original Experiment 104/108 kernel: circular 60 4-bit windows, CENTER=30, left rotation, three-phase scheduler, phase0. Build the same G0 catalog of 130 active localized parents. For each parent, independently generate all 100 candidate initial configurations with the original per-parent/per-attempt RNG formula `3_000_000 + parent_index*300_000 + attempt_index`, assign nonzero raw values to exactly the phase-0 occupied positions, autonomously evaluate for **500 ticks**, and accept only controls matching the exact period, union support, instantaneous occupied positions and scheduler phase. No material intervention or future spread score participates in selection. The first accepted attempt is checked against the original frozen Experiment127 55-parent metadata.

Controls may be in the same coarse class yet differ in their raw microstates. Phase0 control frame is chosen exactly as in Experiment108. Results record every accepted attempt and SHA256 of the accepted microstate (60 raw bytes). Unique-state counts are checked per parent.

## Result

| Accepted candidate controls per G0 parent (100 attempts) | Parent count |
|---|---:|
| 0 | 75 |
| 1 | 33 |
| 2 | 16 |
| 3 | 3 |
| 4 | 2 |
| 5 | 1 |

Total **87 accepted, distinct controls** across **55 eligible parents**. **22 of the 55 eligible parents** have at least two distinct controls; there are **32 additional controls beyond the original first-choice control per parent**.

Thus the first-accepted control is a reproducible *selection convention*, **not** a unique physical null. This finding does not yet say how spread outcomes vary across controls; that is the separately audited Experiment 134. The 87 states are not 87 independent parents and are not evidence of organizational reproduction or learning.

## Reproduce

The full serial run uses Python's standard library:

```sh
python experiments/133_eligible_control_multiplicity/run.py \
  --output experiments/133_eligible_control_multiplicity/results/default.json
python experiments/133_eligible_control_multiplicity/test_smoke.py
```

To reduce uninterrupted runtime, the published `results/default.json` was generated by **four disjoint** catalog intervals `[0,30), [30,60), [60,90), [90,130)`, whose exact outputs are retained as `results/part0..part3.json` and deterministically joined with `merge_parts.py`. They are not four stochastic replicates; no outcomes influence merge or control selection. A serial full run uses exactly the same candidate construction.

## Boundary

Only 100 candidate proposals per parent are evaluated; other controls could exist outside this prespecified search budget. The number of eligible parents (55/130) remains selected by autonomously derived physical constraints. No independent population inference, survival goals, cognitive model, or new kernel rule is established.
