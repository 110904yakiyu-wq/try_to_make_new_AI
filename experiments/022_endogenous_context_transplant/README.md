# Experiment 022 — endogenous local-context transplant

## Question

When repeated history changes the operational quotient, is that change merely a diffuse property of the whole CA state, or is it causally carried by a naturally generated local context near the later assay?

The stronger version of the question is whether the history-dependent quotient can be **switched by moving only the local context**, without changing the rule, probe vocabulary, probe horizon, or training history outside that small region.

## Method

For every ECA rule and every width-3 training pattern:

1. build a one-shot history (`0`) and a repeated history (`0,4,8,12,16`),
2. keep only cases where their baseline operational quotients differ,
3. at the remote assay location, transplant the local CA patch from one history into the other,
4. recompute the exact same probe quotient,
5. find the smallest transplant radius in `0,1,2,4,8` that makes the recipient quotient exactly equal to the donor-history quotient.

The transplanted window has width `core_width + 2*radius`.

A causal control performs the same transplant half a ring away from the assay site. With the default ring size and probe horizon, that location lies outside the relevant local light cone.

No rule, reward, learner, SELF variable, or memory module is changed.

## Default result

Across all 256 ECA rules and eight training patterns:

- baseline history-dependent quotient changes: **202**
- repeated-history quotient switched exactly to the one-shot quotient by a local one-shot patch: **197 / 202**
- one-shot quotient switched exactly to the repeated quotient by a local repeated patch: **191 / 202**
- exact switching worked in both directions: **187 / 202**
- distant transplant produced the donor quotient: **0** in either direction

Minimal radius counts:

### repeated -> one-shot

- radius 0: 0
- radius 1: 49
- radius 2: 103
- radius 4: 32
- radius 8: 13

### one-shot -> repeated

- radius 0: 0
- radius 1: 45
- radius 2: 117
- radius 4: 28
- radius 8: 1

Thus most history-induced quotient changes can be transferred by replacing only a very small locally generated patch around the later probe site.

## Interpretation

This is stronger than deletion/ablation.

The experiment does not merely erase a region and observe that behavior changes. It transfers the **actual pattern generated by a different history**, and in most cases that pattern transfers the donor history's operational quotient with it.

Under this assay, the history-dependent operational identity is therefore often carried by a compact, endogenous local context.

That is compatible with the working idea that useful contexts need not be supplied as semantic objects. A fixed local law can produce a physical pattern that later changes what distinctions are operationally available.

## Important boundary

This does **not** show that the substrate recognizes, copies, selects, or intentionally reuses the patch.

The observer performs the transplant. The result establishes causal sufficiency of an endogenous local context, not endogenous context manipulation.

The next step is to test whether the same naturally generated local patterns recur in situ and carry reproducible operational effects without being moved by the observer.
