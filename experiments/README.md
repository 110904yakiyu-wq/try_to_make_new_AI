# Experiments

This directory is for falsification-oriented prototypes.

Each experiment should state:

- the hypothesis being tested
- which assumptions are intentionally hard-coded
- which cognitive concepts are intentionally absent
- the finite resource budget
- the observable used by us as researchers
- the result, including negative results
- what assumption should be removed or changed next

Experiments do not need to preserve API compatibility or architectural cleanliness.

The first experiment should not try to solve a benchmark. It should test whether an initially untyped finite executable medium can acquire new operational distinctions through its own history without an explicit learner, SELF, reward, or memory module.
