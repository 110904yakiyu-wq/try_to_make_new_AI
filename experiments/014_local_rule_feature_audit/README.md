# Experiment 014 — local-rule feature audit

## Question

Can the strong remote history-dependent response geometry from Experiments 012–013 be explained by a simple property of the eight-entry ECA truth table?

## Features tested

For every one of the 256 ECA rules, compare the Experiment-012 untrained-probe L2 score against simple local descriptors:

- number of `1` outputs in the rule table
- distance from a balanced 4/4 truth table
- algebraic-normal-form degree
- average Boolean sensitivity
- number of permutive input coordinates
- left / center / right permutivity individually

Also group rules under the standard reflection + black/white conjugation symmetries and count how many symmetry orbits appear among the top 30 rules.

## Result

No tested local descriptor explains the effect well.

The largest simple association is average Boolean sensitivity, with Pearson ~0.21 and Spearman ~0.29. All other tested scalar features are weaker. In particular, truth-table density and algebraic degree are poor predictors.

The top 30 rules occupy 21 different reflection/conjugation symmetry orbits. Thus the high-scoring rules are not just many names for one small symmetry family.

## Interpretation

This is a negative result and is useful.

The response-geometry effect appears to depend substantially on **dynamics generated by the rule**, not merely on an obvious static statistic of the local Boolean function.

That pushes the next experiments toward dynamical quantities: propagation, persistence, perturbation growth/decay, domain formation, recurrence, and the relation between those quantities and the low-dimensional response modes.

This does not establish that no local invariant can predict the effect. It only rejects the simple features tested here as sufficient explanations.
