# Experiment 075 — interaction-catalyzed regeneration K10

## Question

K9 showed that passive precarious turnover is not enough. Does a minimal use-dependent regeneration rule create schedule-independent operational adaptation?

## K10 physical change

Keep the K8 self-delimiting event and its shared field `T`.

After each event:

1. rewrite all participating windows normally;
2. select one deterministic nonparticipating width-sized region;
3. overwrite it with the raw shared field `T` generated by the event.

There is no reward, fitness score, activity counter, lifetime, or semantic rule decoding. The only asymmetry is that **an interaction that actually happened leaves one additional physical copy of its collective field**.

## Result

With 16 backgrounds and six washout events:

### Block reversal

- cases: **1152**
- recent advantage: **586**
- older advantage: **542**
- ties: **24**
- strict: **203**

### Irregular equal-count schedule

- cases: **1152**
- recent advantage: **563**
- older advantage: **561**
- ties: **28**
- strict: **208**

The irregular schedule is essentially balanced.

## Interpretation

Generic regeneration of interaction products is still insufficient.

Together with Experiments 074 and earlier retention controls, the evidence now supports a useful negative boundary:

> history dependence, passive precariousness, and generic use-dependent retention do not by themselves create robust adaptive preference for familiar perturbations.

Further tuning of turnover amount, copy rate, or deposition location would be parameter fishing.

The next step should not be another retention formula. It should test a qualitatively different requirement: **consequence coupling through self-maintaining closure**.
