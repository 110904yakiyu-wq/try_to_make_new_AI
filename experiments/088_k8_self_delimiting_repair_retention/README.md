# Experiment 088 — K8 self-delimiting repair retention

## Question

Experiments 086–087 showed that fixed-length repair traces can accidentally encode the target scale, while repair-support-derived spans do not robustly internalize the selected organization.

Return to K8, where an interaction context is self-delimited by the medium's first XOR closure.

If a disturbance is exactly repaired by a K8 event, copy that event's own raw, self-delimited pre-event context forward. Does this create frequency-specific operational adaptation without a fixed retention length?

## Mechanism

For each perturbation exposure:

1. record the pre-disturbance 3-bit local value;
2. apply the perturbation;
3. run the usual K8 event budget;
4. after each event, test whether the disturbed 3-bit value has returned exactly to its pre-disturbance value;
5. if so, copy the repairing event's full raw context (`values`) into the immediately following K8 windows.

The copied length is exactly the event arity. No fixed trace length, period label, reward, weight, or learner is added.

## Frequency-specific assay

For each equal-Hamming-weight perturbation pair P/Q, compare:

- a random 16-exposure schedule containing 12 P and 4 Q;
- the label-swapped schedule containing 4 P and 12 Q.

The schedule positions are identical between the two states; only P/Q labels are swapped.

At test time, measure operational damage using the K8 access-cost landscape. Repair retention is disabled during the test itself so the readout measures the trained state rather than an immediate test-time trace.

Parameters:

- key width = 3
- ring size = 18 bits
- event budget = 3 per exposure
- 8 random initial backgrounds
- min and max K8 scheduler policies
- six spatial training positions
- six equal-weight P/Q pairs
- four independently shuffled schedule geometries

Total comparisons: **2304**.

## Result

### Baseline K8, no repair retention

- matching-frequency advantage: **1129**
- mismatching-frequency advantage: **1112**
- ties: **63**
- strict two-sided cross-over: **354**

### Self-delimiting repair retention

- matching-frequency advantage: **1149**
- mismatching-frequency advantage: **1086**
- ties: **69**
- strict two-sided cross-over: **355**

The directional imbalance in the trace condition is weak (normal approximation z ≈ 1.33, two-sided p ≈ 0.18), and strict cross-over is essentially unchanged.

The trace mechanism was not dormant:

- mean repair-trace deposits per 16-exposure trained state: **4.448**
- fraction of trained states with at least one deposit: **0.936**

## Interpretation

This is another negative boundary.

Removing the fixed retention scale was necessary, but it was not sufficient. Even when the retained material is:

- generated by an actual disturbance;
- retained only after exact repair;
- self-delimited by the substrate's own K8 closure;
- physically copied back into the same medium;

there is no robust frequency-specific operational learning signal under this assay.

Therefore:

`self-delimited repair trace != adaptive consequence memory`

The missing ingredient is not simply a better trace length.
