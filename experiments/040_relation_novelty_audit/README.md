# Experiment 040 — relation-repertoire novelty audit

## Question

Experiment 039 suggested that useful K2 rewrites may need to generate new future relational opportunities.

Does strict joint endpoint causality occur specifically when the first donor rendezvous creates many previously absent relation types?

## Observable

For the default rotate K2, represent a currently executable relation type by:

`(4-bit key, circular endpoint separation)`

For each causal-transfer case:

1. collect the donor relation-type repertoire immediately before its first event;
2. execute exactly that event;
3. collect the repertoire immediately afterward;
4. count newly created and destroyed relation types;
5. compare strict joint-only endpoint-transfer cases against the remaining eligible cases.

## Result

There are 17 strict joint-only cases and 66 other eligible cases.

Mean values:

| group | new relation types | destroyed relation types | before repertoire size | after repertoire size |
| --- | ---: | ---: | ---: | ---: |
| strict joint-only | 11.82 | 11.53 | 15.35 | 15.65 |
| other eligible | 11.27 | 11.38 | 15.97 | 15.86 |

The differences are small.

## Interpretation

The simple hypothesis

> joint causal dependence is strong because one interaction creates unusually many new relation types

is not supported by this audit.

The current K2 joint effect appears to depend more directly on the fact that execution is **enabled by a fixed two-endpoint matching relation** than on exceptional relation-repertoire expansion after the event.

This exposes an important claim boundary: K2 explicitly hard-codes one interaction grammar, namely equality matching between separated key windows. Therefore some amount of relational joint causality is expected by construction.

## Consequence

Do not treat K2's distributed endpoint dependence as emergent relational intelligence.

The next substrate question is harder:

> can the criterion that makes two regions mutually consequential become history-dependent without changing the physical kernel itself?

That requires making the **effective relation grammar** soft while keeping only a minimal fixed physical interaction law.
