# Experiment 053 — strict second-order grammar audit

## Question

K6b has history-dependent relation repertoires and multi-region causal effects. Does history also change the **law by which the current grammar responds to the same next interaction**?

## Strict assay

Start only from equal-budget history pairs whose current ternary repertoires are exactly equal. There are 19 such pairs in the default eight-background sweep.

For each pair, write the same one of eight width-3 bridge patterns at the same physical location.

Then progressively require:

1. current repertoires match before the bridge;
2. repertoires still match immediately after the bridge write;
3. the next selected event has the same content triple;
4. strongest condition: the next event has the same physical positions **and** contents.

After exactly one K6b event, compare the resulting repertoires.

## Result

- initial same-repertoire pairs: **19**
- bridge trials: **152**
- repertoire still equal immediately after bridge: **95**
- among those, same next-event content triple: **92**
- among those, exact same next event including positions: **69**

Post-one-event repertoire divergence:

- among the 95 post-bridge-equal trials: **1**
- divergence while event contents are also equal: **1**
- divergence while the full physical event is equal: **0/69**

The single surviving weak divergence uses the same event contents but applies them at different physical positions.

## Interpretation

Under this assay, K6b does **not** provide evidence that identical current operational grammar plus an identical next physical interaction can evolve according to a history-conditioned grammar-update law.

Its history dependence is still carried by the detailed current medium and by which physical relation gets selected.

That is useful dynamics, but it is weaker than the project's target notion of changing the *kind of future dependencies*.

## Next move

Rather than adding another meta-rule layer, change one physical assumption: stop fixing interaction arity.

A next substrate should allow pair, triple, and higher-order interactions to emerge from the same content relation, so history can change not only which relation is active but the **arity/type of dependency** that can execute.
