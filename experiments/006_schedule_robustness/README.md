# Experiment 006 — exposure-spacing robustness

Rule 129 showed a distributed repetition-dependent effect in experiment 005.

Before treating that as interesting, test whether it is only a resonance artifact of the chosen 4-step exposure schedule.

## Question

Does repetition gain survive when the spacing between repeated exposures changes?

For each candidate rule, use five exposures at:

`[0, s, 2s, 3s, 4s]`

for spacings `s = 2..8`.

Use a fixed probe time so every condition is measured at the same absolute time.

Measure repetition gain relative to a one-shot exposure at:

- offset 0 (training location)
- offset 20 (distributed transfer location)

## Interpretation

A highly spacing-specific sign flip suggests ordinary dynamical resonance.

A same-direction effect over many spacings is a stronger sign that the medium has a robust history-dependent response tendency, although it still does not imply learning or intelligence.
