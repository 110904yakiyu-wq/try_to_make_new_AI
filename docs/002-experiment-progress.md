# Experiment progress 000–009

Date: 2026-09-14

This is a hobby log, not a paper claim.

## What survived the first implementation loop

### 000 — null substrate

A fixed Rule 110 medium can encounter new local contexts that split provisional observer-defined equivalence classes.

Useful only as a measurement sanity check.

### 001 — reusable context

Recurrence + discriminating power was far too weak a criterion: hundreds of contexts passed.

Rejected as a proxy for learning or understanding.

### 002 — fixed-budget quotient

With exactly the same observer assay budget at every timestep, the operational quotient changed 5 -> 7 -> 8 -> 7 -> 8 classes.

Operational identity can be transient and reversible without changing the physical rule.

### 003 — Rule 110 familiarity cross-over

No robust simple experience-specific familiarity effect in the default Rule 110 assay.

Important: this was a property of Rule 110 under this assay, not a proof about fixed CAs.

### 004 — all 256 ECA rules

Several fixed rules showed much larger repeat-count-dependent persistent effects.

Therefore the idea "we must add a mutable rule field" was rejected for now.

### 005 — spatial transfer

Rules 195/153/203 looked mostly like local residue.

Rule 129 showed repetition-specific effects over a much wider causal region.

### 006 — timing robustness

Rule 129's remote effect survived exposure spacings 2..8, although the local sign and amplitude were schedule-dependent.

So it was not just one exact 4-step resonance.

### 007 — response geometry

After Rule 129 was repeatedly exposed to A/B at one location, remote response changed for all six 3-bit probe patterns never used during training.

History was changing a broad intervention->consequence map, not only literal A/B re-exposure.

### 008 — training-pair sweep

All 28 unordered 3-bit training pairs produced nontrivial remote response-geometry changes under the default Rule 129 assay.

The original A/B pair was not unique.

### 009 — low-dimensional modes

Across the 28 training histories, response-geometry changes were strongly aligned:

- mode 1: ~63.5% centered variance
- modes 1+2: ~87.8%
- modes 1..3: ~94.7%

A within-row probe-label shuffle null put the top-two mean near ~51.8%, with the observed value above every one of 500 default null trials.

This suggests that different histories do not merely leave unrelated high-dimensional response residue. They alter later interaction responses through a small number of shared observer-visible modes.

## Current interpretation

Do **not** call this learning yet.

Rule 129 is a fixed deterministic local law. Propagating domain/phase structure remains an adequate mechanistic explanation.

But that is already useful for the original design question:

> fixed physics can support history-dependent, distributed, low-dimensional modulation of future interaction structure without adding a neural network, reward, memory module, self variable, or explicit meta-layer.

The low-dimensional mode itself must also not be reified into a built-in latent variable. It is an observer description of the dynamics.

## Current next question

Does the low-dimensional organization recur across changes in probe position, probe time, and probe family?

Preliminary checks suggest:

- low dimensionality remains strong under changed timing/location;
- the exact mode orientation drifts substantially.

That is potentially more compatible with a metastable organization than with a single fixed internal representation.

The next experiment should quantify this cross-condition recurrence/drift before adding any new physical primitive.
