# K8 learning boundary

Date: 2026-09-14

## What K8 established

K8 is the first substrate in this repository that gave a reasonably clean operational notion of resource-sensitive context.

Under one fixed self-delimiting physical rule, history can change:

- which interactions are reachable;
- which arities execute;
- which transformation identities exist;
- how many prefix windows must be scanned to reach a transformation;
- which different micro-contexts are operationally equivalent because they implement the same cost-reduction role.

Experiments 059–061 are especially important:

- a history-generated context can causally shorten access to the same transformation identity;
- breaking the critical context destroys the shortening;
- the same context works when recreated by another history;
- different raw contexts can implement the same operational accelerator role.

This is genuine history-dependent reorganization of finite-resource computation.

## What K8 did not establish

Experiments 063–067 deliberately tried to turn those effects into something learning-like.

They failed under progressively stronger assays.

### Repetition is not enough

Five repetitions of A do not robustly make an A-probe cheaper than five repetitions of B.

### Generic retention is not enough

Raw event traces, generic copying, and local recurrence-gated copying do not create a reliable A/B cross-over.

### Making CPU cost physical is not enough

Replacing fixed event count with fixed real work budget changes execution opportunity, but still does not produce robust experience-specific compilation.

### Raw state recovery is misleading

Repeated perturbation creates a familiar-perturbation advantage in Hamming return to the prior bit state, but that advantage disappears when recovery is measured in the operational transformation/cost landscape.

### Continuation count is not adapted either

Under fixed CPU work budget, a familiar perturbation does not reliably allow more events to execute.

## Main conclusion

The repository now has a sharp boundary:

`history dependence != learning`

and

`reusable operational context != adaptive retention`.

K8 supplies variation and memory-like hysteresis, but it lacks a physical reason for useful organization to continue preferentially.

## Next minimal assumption

The next substrate should not add a reward function or a semantic learner.

It should add only **precariousness**:

- finite work remains fixed;
- successful endogenous interaction helps preserve/reconstitute the medium;
- failure to sustain interaction causes ordinary physical degradation;
- no external score says which pattern is good;
- selection occurs only through differential continuation of organization.

This is the smallest next move that directly addresses the missing causal loop instead of tuning more trace formulas.

The falsification criterion is strict: if a precarious substrate still does not develop perturbation-specific operational recovery, stop calling the phenomenon learning and reconsider the foundation again.
