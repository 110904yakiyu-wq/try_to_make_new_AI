# 023–024 — Initial autonomous recurrence confounds material-induced persistence

Experiment 123 holds fixed 15 equal-edit-window-budget and raw-source-distance matched patch contexts (Exp120/121), generated from the 112 exact support/phase on-cycle G0/control cohort. All selected states are evolved with **no newly injected boundary raw material**, allowing the physical bits already edited by the transplant or null to interact autonomously until exact recurrence at `microstate+next scheduler phase` or right censor at ticks 500/2000.

Width 1/2 G0 transplant and equal-budget null both recurrent-connected by 500 in all 3/5 patch contexts. Width 3: G0 transplant connected by 500 in a parent-weighted 60%, equal-edit null 40%, with each arm censored at 40% by both 500 and 2000. Thus the previous held-out boundary perturbation experiment 122 did not begin from dynamically equivalent viable baselines.

Experiment 124 joins the 122 and 123 frozen records without another simulation and stratifies each patch: width-3 both autonomously connected: 3 patches/2 parents, downstream donor−null connected=+0.02083, censor=−0.02083; both autonomously censored: 3 patches/2 parents, donor−null connected=−0.04167; mixed resolved one patch/one parent, donor−null connected=+0.58333, censor=−0.54167. The latter starts with transplant connected vs null static and cannot be attributed to injected raw material. Parent counts remain tiny and strata are selected on downstream-from-intervention microstate properties, so this is not a causal mediation estimate.

**Causal audit conclusion:** No support for identifying a G0-specific self-maintaining or learning mechanism from transplant-to-G0 response similarity or finite-horizon recurrent-class rates. Several successive asymmetries were exposed: source-bit identity, nonmatching edited-site number, nonmatching edited-site location, initial autonomous recurrence and strong censoring. The original conditional G0 vs matched-on-cycle control persistence association in 108 is still an observation, but its mechanistic explanation is open.

Next priority: explicit **partial identification bounds under right censoring** before any further narrow patch-control search, plus accurate eligibility-flow reporting. A comparison can be inconclusive even when one observed finite-time connected count is larger.
