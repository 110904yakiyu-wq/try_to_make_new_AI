# 056–058 — External multi-episode experience is not learning

Exp156, Exp157, and Exp158 retain the same 104/139 deterministic 60 × 4-bit left-rotation local kernel and three-phase scheduler. No learning objective, reward, self variable, memory register, agent boundary or special reproduction instruction is introduced.

## Measurement correction before claims

Exp156 applied heldout raw material at a location one additional position *outside* the nearest original support boundary. Under sham, all 1,040 eligible response records showed exactly one affected position. This degeneracy is structurally related to the geometry of isolated raw bit deposits and is **not** useful evidence of no learning or superior confinement. Moreover, no four-arm original-boundary material-addition test has all test cells empty after the scripted training pulses. Instead of relaxing the no-overwrite rule post-hoc, Exp157 predefines a nontrivial physical *XOR bit flip* at the original boundary. This changes only the **test intervention**, not the kernel, and is documented as a separate experiment.

## Genuine finite-observer contrast

Exp157: two scheduled raw material pulses (7 left, 11 right; tick0/24) versus sham, single pulses, reverse order, and simultaneous pulses. The strict common-arm test cohort contains 111 of 130 original G0 parents, two nearest boundary sites and four disjoint test masks (1,2,4,8), with all arms aligned at test tick96 phase0. A heldout mask affects on average 3.4685 positions for sham, 9.2782 for left-first, 9.1453 for right-first, 9.7072 for simultaneous over 60 subsequent ticks. This is **greater susceptibility** (worse under the observer's locality objective), not acquired functional gain. Both externally imposed ordering and bit content are physical interventions; their effects do not establish endogenous learning.

Exp158: even in the same 111-parent set, left-then-right prior experience shifts total raw popcount by +9.0901 and phase0 occupied-window count by +3.7387 on average. There are **0/111** two-pulse parents satisfying *both* sham popcount and occupied-window equality; no distinct prior-history arm has exactly the same full microstate as sham. Thus there is no support for controlling the physical baseline in this assay. Initial t1 XOR response difference is small (+0.1475 positions) compared to t60 (+4.7714) and union60 (+5.8097), consistent with ordinary nonlinear local amplification of initial material differences.

## Permissible and forbidden claims

Established: scheduled external pulses alter later causal physical response; multiple pulses on these input sites do not improve the chosen locality metric; short-time response differences amplify over 60 physical ticks; strict pretest state-matching for multi-pulse vs sham has zero coverage here.

Not established: endogenous learning, adaptation, memory as a separate physical field, improvement at another functional task, intrinsic selection of input schedules, self-maintenance, goals, reproduction, heredity, or SELF. Deterministic microstate + scheduler phase fully determines continuation. Observer criteria are not internal preferences. Avoid calling increased susceptibility an acquired skill.

**Next causal gate:** Either design an *input-conditioned functional computation task* with explicitly specified input/output and generalization measured only on new inputs, or develop a prospective control protocol able to match more of the pretest physical state without using evaluation outcomes. A post-hoc successful task must be registered separately from this negative locality assay.
