# 019 — Conditional distance compensation changes the heldout response comparison

**Experiment 119** follows the Experiment 118 preoutcome physical-null feasibility census. A distinct alternate microstate can match the G0 patch transplant in raw 4-bit Hamming distance to the source G0 **only when an additional window is edited** relative to the old fixed-patch null under the current construction. The 118 fixed physical feature and phase-mask constraints remain; full search examines only one supplementary originally G0/recipient-different site and all nonzero values.

Over matched 28 patch contexts with compensated controls (10/9/9 by edit width, representing 9/9/6 parents), original nearest-null and compensated nearest-null were selected using six train raw-value probes (1/7/15 on two sides) at ticks 1 and 3. Heldout other 24 probes at tick 24 yield donor−compensated response Jaccard parent means +0.00134/−0.00224/+0.03068, versus donor−original nearest means −0.02337/−0.05784/+0.02207 on exactly the same patch contexts. Width-3 donor wins/losses vs compensated are 2/4 parents. These figures are descriptive, underpowered, and population-conditional.

This weakens the motivation for treating the original width-3 effect as an autonomous temporal causal role; at minimum, original fixed-patch alternatives did not have equal raw proximity to the evaluation reference. However **compensated and donor edit budgets differ by one window** and positivity is limited to 28/57 original feature-eligible patches, so the design cannot attribute the contrast solely to distance.

No kernel physics, goal, learner, memory or reproductive primitive added. A next stronger null should require both equal physical raw Hamming to G0 and equal number of edited windows, allowing a one-for-one changed-site exchange instead of an additional edit. First audit feasibility *without any downstream response evaluation*.
