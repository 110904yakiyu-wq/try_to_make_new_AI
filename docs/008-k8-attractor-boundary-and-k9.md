# K8 attractor boundary and K9 rationale

Date: 2026-09-15

## What K8 genuinely achieved

K8 is still useful. Without a learner, reward, weight matrix, persistent graph, or explicit memory object, it produced:

- history-dependent operational repertoires;
- self-delimiting variable-arity interaction;
- reusable local contexts that reduce access cost;
- multiple different micro-contexts implementing the same operational accelerator role;
- history-dependent possibility/cost landscapes.

These remain the strongest results of the substrate sequence.

## What K8 did not establish

Repeated perturbation histories can produce long-lived, experience-related recovery biases. However Experiments 068–073 show that this effect is:

- strongly dependent on schedule geometry;
- nonuniform across spatial test position;
- fragile under large state restoration;
- persistent for hundreds of autonomous events;
- almost perfectly associated with entry into different deterministic limit cycles.

In Experiment 073, 568/576 block-reversal history pairs entered different eventual cycles. The 8 pairs that entered the same cycle were all operational ties after long washout.

Therefore the long-lived K8 reversal signal is best treated as **basin-selection hysteresis**, not as evidence of adaptive learning.

## Consequence

Persistent history dependence is too weak a criterion.

A useful next substrate must make organization genuinely precarious: current organization should need to be continually regenerated rather than merely remain encoded in a stable deterministic attractor.

## K9 minimal change

Add only one physical turnover rule to K8:

- perform the normal self-delimiting K8 interaction;
- identify bits participating in that event;
- deterministically flip one currently nonparticipating bit;
- store no age, reward, fitness, activity counter, or lifetime variable.

This implements the weakest version of:

> unused structure is not perfectly persistent.

The first falsification question is not whether K9 is intelligent. It is whether this minimal precariousness breaks K8's attractor-locking and improves experience-specific operational adaptation under irregular schedules.

If it does not, do not tune the decay rate. Record the failure and move on.
