# 059 — History-dependent physical behavior without an independent memory primitive

Experiment 159 restores the original 104/139 three-phase deterministic 60-window 4-bit kernel and compares two externally supplied input schedules, containing precisely the same raw7/11 material, positions and number of events, in the two chronological orders. It reuses Experiment 157's independently frozen eight heldout XOR responses.

Of 130 G0 seed-derived parents, 111 support both intervention schedules (without overwriting occupied positions). Their absolute-tick96 phase0 states are **identical in 24 parents**, and all **192 heldout physical response probes** match exactly on this subset. In the remaining 87 parents the full current states differ, and all 87 show at least one future probe-response difference. The parent-level mean signed order difference is only +0.1329 affected windows, with 24 positive, 25 negative and 62 ties.

This demonstrates a physical distinction between some input orders, not an extra state variable for history. The Markov contract is `(full physical microstate, next scheduler phase)`; if those are equal, the entire future is equal for the same subsequent interventions. A nonzero difference when those differ is expected ordinary nonlinear dynamics, not learned adaptation. Current CPU-AI has not established endogenous goal formation, performance-directed plasticity, generalization after experience or independent memory machinery. Experiment 156's distant-site sham degeneracy and Experiment 158's pretest physical feature mismatch further prohibit any functional-learning claim from the two-pulse history series.
