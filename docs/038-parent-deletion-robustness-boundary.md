# 038 — Adversarial eligible-parent deletion sensitivity (Experiment 138)

Using the 55 G0/control pairs and the already measured thirty intervention conditions per parent, compute each parent's exact lower/upper contribution to the G0−control spread contrast. For any integer k, enumerate the extremal *sums* analytically: to maximize the retained contrast after k deletions, retain the 55−k parents having the largest upper contributions; for the minimum retain the smallest lower contributions.

At threshold 10, the G0−control difference remains strictly negative after **any 0–23 parent deletions** among the matched 55; the first nonnegative extremal retained upper difference becomes possible after 24 deletions. At threshold 60, the corresponding values are 0–25 and 26 deletions. This calculation respects one unknown 60-position event by using the parent's upper endpoint.

This is a post-outcome sensitivity envelope, not a legitimate selection algorithm, significance test, or transportability justification to the 75 unmatched parents. It checks how concentrated the observed within-eligible association could be. No physical, learning, reproduction, or cognitive mechanism is inferred.
