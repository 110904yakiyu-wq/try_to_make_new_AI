# try_to_make_new_AI

新しいAIっぽいものを適当に試すための実験場所です。

これは研究用の正式なリポジトリではなく、ただの趣味です。
思いついたことを試したり、壊したり、やっぱ違うなと思ったら捨てたりします。

失敗した実験や微妙だった案も、気が向けばそのまま残します。
Gitの履歴も含めて、試行錯誤の置き場くらいの感覚です。

Transformerやニューラルネットワークを前提にせず、
「そもそも知能って何なんだろう」「もっと根本から別の作り方がないか」みたいなことを、CPUで遊べる範囲から試しています。

完成品を作ることより、面白そうな方向を実際に動かして確かめることを優先します。

気楽にやります。
